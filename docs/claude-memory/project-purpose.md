The Wüsten-Adventure (desert text-adventure with web GUI) is **NOT a product** — it is
**teaching material** for courses on: Python; "Python programming with AI" (Gemini);
and using a coding assistant (Claude Code). It also contains some JavaScript (the
`web/` front-end).

**Why:** the author teaches these courses.
**How to apply:** favour **clarity and explainability** over cleverness — the code is
read and understood by learners. Keep changes small and well-explained. The dog NPC
was hand-written by the author (with ChatGPT/Gemini help); the **zombie NPC was
written autonomously by Claude Code**, and the author wants to understand it. See
[[gameplay-and-npcs]].
