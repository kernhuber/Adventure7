# Gameplay & UI changes (branch `Adventure-10-2026-06-26-Gameplay`)

After the refactor phase (Steps 1–3, see the `REFACTORING-*.md` docs), work moved to
gameplay and the web UI. This is **teaching material** (Python / AI-with-Gemini /
Claude-Code courses, plus some JS), so changes favour clarity.

## Gameplay

- **Felsnische** — the place `p_felsen` was renamed to `p_felsnische` (display
  "Felsnische") so it is no longer confused with the rock object `o_felsen` (which
  stays "Felsen"). Touches `data/world.json`, `place_prompts.py`, `way_prompts.py`,
  `explosion_state.py`. Internal way keys (`w_felsen_*`) were intentionally left.
- **Refillable bottle** — `o_flasche` can be refilled at the water dispenser
  (`o_wasserspender`, "Trinkbrunnen") in the U-Bahn: `anwenden flasche wasserspender`
  (either direction). One fill = one reserve drink (+20), modelled by the existing
  `flasche_voll` flag; refillable arbitrarily often. Drinking from an empty bottle is
  now guarded (was a latent bug). See `game_apply_functions.py`.
- **Pretty names** — `verb_take` / `verb_drop` / `verb_examine` show call-names
  (capitalized) instead of internal `o_…` ids.

## NPCs / dialog

- **Zombie awakening opens the chat modal.** Taking the wallet spawns the zombie
  (`game_take_functions._awaken_zombie`, state `AWAKENING`); on its turn it issues an
  `interaktion` so the chat modal opens with its line ("Suchst du etwa … die hier?").
  Fixed a bug where the zombie branch of `run_npc_turns` didn't forward `dialogs`, so
  any zombie-initiated dialog never reached `do_chat`.
- **Zombie bite** → a distinct `zombie_bite` NPC action → a dramatic red popup
  (`web/bite_overlay.js`) plus a red flash of the Status panel. Life energy == thirst
  (`thirst_counter`), so the bite (−5) shows there.
- Dog growls / NPC dialogs go through the **chat modal** (`interaktion` →
  `async_verb_interact` → `do_chat`); dog/zombie status lines are debug-only.

## Web UI (`web/`)

- **Dog as an icon.** The "Hund" panel was removed; the dog is a corner icon
  (`web/dog_overlay.js`, next to the zombie and the power lightbulb), shown when the
  dog is at the player's location. Frame blinks **yellow** when angry, **red** when
  attacking. Backend sends `dog.here` / `dog.mood` in the serialized state.
- **Red zombie chat modal** vs. green dog modal (`web/zombie_chat.js`, themed by
  speaker).
- **2×2 panel layout** — Szene | Umgebung (top, equal) / Letzte Aktion | Status
  (bottom).
- **"Letzte Aktion" transcript** — cleared on each new input; shows
  `Eingabe: <input>`, a separator, then each atomic command (`action_label`, the
  parsed function call rendered readably, e.g. "gehe Schuppen") and the engine
  response. The old in-panel debug line moved to the logfile.

## Debug logging

- `utils.dprint`/`dpprint` prefix each log line with the debug level (`l.name`, e.g.
  `WEBGUI: …`).
- The full user input and the per-command debug info are logged via the new
  `dl.CMDLOG` flag (`command_engine.handle_command`).
